WEBSITE USE
Place every PNG at the exact same CSS position and switch opacity as the page scrolls. Use object-fit: contain. Do not morph between frames because that can distort the face and hands; use short 120 to 180 ms crossfades instead.

Suggested scroll order:
00 -> 01 -> 03 -> 04 -> 05 -> 06 -> 02

The Anjali pose works well as the final calm pose.
